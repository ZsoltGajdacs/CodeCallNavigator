# Security reporting

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/ZsoltGajdacs/CodeCallNavigator/security/advisories/new).
Do not disclose vulnerabilities, exploit details or sensitive data in public
issues. Ordinary bugs belong in the bug-report issue form.

Include the affected version or commit, impact, reproduction steps and a minimal
proof of concept when available. Remove credentials, private source code and
personal information. Test only systems and data you own or have permission to
test.

This is a personal project maintained by Zsolt Gajdacs. Reports are handled on a
best-effort basis, with attention focused on the latest code and release. There
is no guaranteed response, remediation timeline, fix, security support or bounty,
and older versions have no maintenance commitment.
