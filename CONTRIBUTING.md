# Reporting bugs and requesting features

CodeCallNavigator is a personal project maintained by Zsolt Gajdacs. Public
contributions are limited to bug reports, feature requests and information needed
to clarify those issues. Use the [issue forms](https://github.com/ZsoltGajdacs/CodeCallNavigator/issues/new/choose)
and search existing issues before opening a new one.

Outside code patches and documentation submissions are not accepted. Pull request
creation is restricted to repository collaborators. General support requests and
GitHub Discussions are not offered. There is no guaranteed response, support,
fix, release schedule or feature implementation. Issues may be closed without
action at the maintainer's discretion.

For bugs, include the app version or commit, installation method, operating
system, relevant analyzer and toolchain versions, reproduction steps, and expected
versus actual behavior. A small reproduction, screenshot or log can help, but is
optional. For features, explain the problem and desired behavior; alternatives
and examples are welcome. Keep comments focused on clarifying the issue.

Only share material you are allowed to publish. Remove credentials, tokens,
private source code, personal information and identifying filesystem paths from
reports, logs, screenshots and reproductions. Do not upload an entire private
repository. Report vulnerabilities through [private security reporting](SECURITY.md),
not public issues.

Follow the [conduct policy](CODE_OF_CONDUCT.md). The contribution policy does not
restrict your rights to use, modify, fork or redistribute the software under its
[license](LICENSE).
